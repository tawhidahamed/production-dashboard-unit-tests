
# Production Dashboard Unit Tests

DevOps Engineering (AT00CK37)
LAB University of Applied Sciences

## Project Description
This project tests selected JavaScript utility functions from the AT00CK37-3004 library.

The hypothetical application is a Production Monitoring Dashboard designed to track production quantities, calculate performance metrics, and validate production data.

## Testing Approach
The project uses Mocha and Chai for unit testing, GitHub Actions for continuous integration, and Coveralls for coverage reporting.

Ten critical functions are selected using MoSCoW prioritization.
